# 💰 Expense & Budget Visualizer

A mobile-friendly expense tracker web application built with HTML, CSS, and vanilla JavaScript.

## 🌟 Features

### Core Features (Required)
- ✓ **Form Input**: Add expenses with Item Name, Amount, and Category (Food, Transport, Fun)
- ✓ **Transaction List**: Scrollable list of all expenses with delete functionality
- ✓ **Total Balance**: Automatically updated total expenses display
- ✓ **Pie Chart**: Visual representation of expenses by category using Chart.js

### Optional Features (3 implemented)
- 🌙 **Dark/Light Mode Toggle**: Switch between themes with persistent preference
- ▪ **Sort Transactions**: Sort by date, amount (high/low), or category
- ! **Budget Limit Alert**: Set budget limit and get visual warnings when exceeded

## → How to Use

1. **Set Budget Limit** (Optional): Enter your budget limit at the top and click "Set Limit"
2. **Add Expense**: Fill in the form with:
   - Item Name (e.g., "Lunch")
   - Amount in Rupiah (e.g., 50000)
   - Category (Food, Transport, or Fun)
3. **View Expenses**: See all your transactions in the list below
4. **Sort**: Use the sort dropdown to organize expenses
5. **Delete**: Click the delete button to remove an expense
6. **Toggle Theme**: Click the moon/sun icon to switch between dark and light mode

## 📱 Mobile Responsive

This app is optimized for mobile devices and works seamlessly on all screen sizes.

## 💾 Data Storage

All data is stored in browser Local Storage, so your expenses persist even after closing the browser.

## 🛠️ Technical Stack

- HTML5
- CSS3 (with CSS Variables for theming)
- Vanilla JavaScript
- Chart.js (for pie chart visualization)
